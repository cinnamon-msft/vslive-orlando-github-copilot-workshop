# Product

## Register

brand

## Users

Developers attending the VS Live! Orlando 2026 workshop with Kayla Cinnamon and Jon Galloway. They will work from laptops in a conference room, move between instructor-led and self-guided exercises, and may return later to finish. Most can use Windows, macOS, or Linux; the Visual Studio 2026 lab requires Windows.

## Product Purpose

Provide one trusted path through four GitHub Copilot experiences: Copilot app, CLI, VS Code, and Visual Studio 2026. Success means attendees can prepare once, understand where they are in the day, launch the correct starter project, complete each lesson in sequence, and resume without searching across separate repositories.

## Brand Personality

Electric, mechanical, assured. The experience should feel like a well-run live technical production: vivid enough to create momentum, structured enough to reduce anxiety, and precise enough to trust during hands-on work.

## Anti-references

- Generic SaaS landing pages made from interchangeable feature cards.
- Terminal cosplay where monospace type substitutes for real hierarchy.
- Low-contrast neon, gradient text, decorative glass panels, or motion that competes with instructions.
- A direct visual clone of any source workshop.
- Dense documentation that loses the event narrative and the four-part progression.

## Design Principles

1. Keep the whole day visible: every page should reinforce the learner's place in the four-lab path.
2. Practice what the workshop teaches: make the interface feel intentional, current, and technically credible.
3. Optimize for the room: critical actions, state, and instructions must remain legible under conference lighting and projection.
4. Preserve source truth: adapt navigation and paths while keeping substantive lab instructions and provenance intact.
5. Reward forward motion: make starting, completing, and resuming feel immediate without requiring an account.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support complete keyboard navigation, strong visible focus, semantic landmarks and headings, high-contrast prose and code, 320px-wide screens, browser zoom, reduced motion, and a light theme for attendees who find the default dark theme difficult in bright environments. Progress and theme preferences stay local to the browser.
